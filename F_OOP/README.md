* Constructors

* Inheritance

* Method Overloading
* Method Overriding
* Abstraction
* Interfaces
* Access Modifiers
* `this` & `super` Keywords

## 💻 Example

```java
class Student {
    String name;

    void display() {
        System.out.println("Name: " + name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();

        student.name = "Uday";
        student.display();
    }
}
```
