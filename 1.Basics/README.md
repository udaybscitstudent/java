## 💻 Example Program

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## ⚙️ How to Run

Make sure Java is installed on your computer.

Check the Java version:

```bash
java --version
```

Compile the program:

```bash
javac HelloWorld.java
```

Run the program:

```bash
java HelloWorld
```
