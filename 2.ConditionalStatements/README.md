# Java Conditional Statements 🔀

This repository contains my **Java Conditional Statements concepts and practice programs**.

## 📚 Topics Covered

* `if` Statement
* `if-else` Statement
* `else-if` Ladder
* Nested `if`
* `switch` Statement
* Ternary Operator `?:`
* Relational & Logical Operators

## 💻 Example

```java
public class ConditionalExample {
    public static void main(String[] args) {

        int age = 22;

        if (age >= 18) {
            System.out.println("Eligible to vote");
        } else {
            System.out.println("Not eligible to vote");
        }
    }
}
```
