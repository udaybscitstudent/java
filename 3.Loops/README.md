# Java Loops 🔄

This repository contains my **Java Loop concepts and practice programs**.

## 📚 Topics Covered

* `for` Loop
* `while` Loop
* `do-while` Loop
* Nested Loops
* Enhanced `for` Loop
* `break` Statement
* `continue` Statement

## 💻 Example

```java
public class LoopExample {
    public static void main(String[] args) {

        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}
```
