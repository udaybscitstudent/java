# General Programming

This repository contains a collection of commonly used **programming problems and logical programs** for practicing problem-solving and programming fundamentals.

## Programs Included

* [Prime Number](Prime.java)
* LCM (Least Common Multiple)
* HCF / GCD (Highest Common Factor)
* Binary to Decimal
* Decimal to Binary
* Leap Year
* Palindrome Number
* Armstrong Number
* Perfect Number
* Factorial
* Fibonacci Series
* Reverse Number
* Sum of Digits
* Even and Odd Number
* Swap Two Numbers
* Greatest of Three Numbers
* Multiplication Table
* And other common programming problems

## Purpose

The main purpose of this repository is to practice:

* Programming logic
* Problem-solving
* Loops and conditions
* Functions
* Number systems
* Mathematical operations
* Basic algorithms
