# 📌 1. Introduction to OOP

**Object-Oriented Programming (OOP)** is a programming paradigm based on the concept of classes and objects.

It helps developers write reusable, maintainable, secure, and organized code.

Java is an object-oriented programming language that uses OOP concepts to develop real-world applications.

### 🎯 Why OOP?

* ✅ Code Reusability
* ✅ Data Security
* ✅ Code Maintainability
* ✅ Modularity
* ✅ Flexibility
* ✅ Real-World Modelling

---

# 📚 2. Four Pillars of OOP

Object-Oriented Programming is based on four major principles:

<div align="center">

|      Concept     | Description                                                   |
| :--------------: | ------------------------------------------------------------- |
| 🔵 Encapsulation | Wrapping data and methods into a single unit.                 |
|  🟢 Inheritance  | Acquiring properties and methods of another class.            |
|  🟣 Polymorphism | Performing one task in different ways.                        |
|  🟠 Abstraction  | Hiding implementation details and showing essential features. |

</div>

---

# 🏗️ 3. Basic Concepts of OOP

Before understanding the four pillars, let's explore the fundamental concepts.

### 1. Class

A class is a blueprint or template used to create objects.

### 2. Object

An object is an instance of a class that represents a real-world entity.

### 3. Constructor

A constructor is a special member of a class used to initialize objects.

### 4. Method

A method is a block of code that performs a specific task.

---

# 🔵 4. Encapsulation

### 📖 Definition

Encapsulation is the process of wrapping data members and methods into a single unit (class) and controlling access to them using access modifiers.

### 🔑 Important Concepts

* Data Hiding
* Private Variables
* Getter and Setter Methods
* Access Modifiers

### 💻 Example

```java
class Student {

    private int roll;

    public void setRoll(int r) {
        roll = r;
    }

    public int getRoll() {
        return roll;
    }
}
```

---

# 🟢 5. Inheritance

### 📖 Definition

Inheritance is a mechanism in Java through which one class acquires the properties and methods of another class.

### 📚 Types of Inheritance

1. Single Inheritance
2. Multilevel Inheritance
3. Hierarchical Inheritance
4. Multiple Inheritance (through interfaces)
5. Hybrid Inheritance (possible through interfaces)

### 🔑 Important Keyword

`extends` – Used to inherit a class.

`implements` – Used to implement an interface.

---

# 🟣 6. Polymorphism

### 📖 Definition

Polymorphism means one name with multiple forms.

It allows a method or object to behave differently in different situations.

### 📚 Types of Polymorphism

1. Compile-Time Polymorphism

   * Method Overloading
   * Constructor Overloading

2. Runtime Polymorphism

   * Method Overriding
   * Dynamic Method Dispatch

---

# 🟠 7. Abstraction

### 📖 Definition

Abstraction is the process of hiding implementation details and showing only essential functionality to the user.

### 🔑 Mechanisms of Abstraction

1. Abstract Class
2. Interface

### Important Keywords

* `abstract`
* `interface`
* `extends`
* `implements`
